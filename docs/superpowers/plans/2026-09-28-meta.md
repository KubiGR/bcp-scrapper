# Meta Page Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Meta page showing which factions and archetypes (faction + detachments) are played most across recent big events, how they perform (win rate, X-1 or better), and which factions top teams bring more often than teams overall.

**Architecture:** One query loads the counted players of big events in a range (faction, record, current list's army and detachments, team and team placing); pure shared functions `computeMeta` and `computeTeamMeta` aggregate them; `GET /api/meta` returns the result. The web page renders a sortable faction table with expandable archetypes, a team section and a drill-down reusing the Top lists search.

**Tech Stack:** as plans 1–8 (Hono, Drizzle/Postgres/PGlite, Zod 4, React 19 + Compiler, Mantine 9, TanStack Router/Query, Vitest, Playwright).

**Spec:** `docs/superpowers/specs/2026-09-28-meta-design.md`.

## Global Constraints

- Node 24, pnpm 12, TypeScript `~6.0.3`, Zod 4; strict ESLint `--max-warnings=0`, no `any`, no non-null assertions; Prettier.
- Tests next to the code; PGlite only; no network; never read, print or source `.env`.
- No new BCP requests, no new tables; computed on request.
- Counted player: big event in range, wins + losses + draws > 0. Faction via `resolveFaction`; null → "Unknown faction". Archetype: faction + current read list's detachments; none → "Detachment unknown".
- Win rate = (wins + ½ draws) ÷ games; X-1 or better = losses ≤ 1; share = players ÷ all counted players.
- Top teams: per counted team event (every team has a placing), placing ≤ `ceil(teams × 0.25)`.
- Minimum players default 5 (1–50): dimmed and sorted last, never hidden (web only).
- Win-rate colours as the matchups heatmap: red < 45 %, neutral 45–55 %, green > 55 %.
- Mantine 9.6.2 dark theme; keyboard reachable; no manual memoisation; loading/empty/error states; figures `className="numeric"`.
- `pnpm vitest run --project api|web|shared <path>`; commit trailer `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`; build in a worktree.

## Review Focus

1. **Stale lists** must not supply detachments or armies (join only the player's current list, `storedCurrentList`). _Task 1 test._
2. **Team events without complete placings** (running, or some team without a placing) are left out of the team section entirely, not partially counted. _Task 1 test._
3. **Small team events** (e.g. 3 teams → top 1; 1 team → top 1) don't divide by zero or produce NaN shares. _Task 1 test._
4. **Players with a guessed army** count in that faction; allegiance-only without a list → Unknown faction. _Task 1 test._
5. **Huge ranges** (a year, thousands of players) stay one query plus in-memory aggregation, no per-event loops. _Task 1 (implementation note; checked in review)._

```ts
import type { ArchetypeRow, MetaRow, TeamMetaRow } from './meta-schemas';

export interface MetaPlayerRow {
  eventId: string;
  isTeamEvent: boolean;
  teamId: string | null;
  teamPlacing: number | null;
  faction: string | null;
  detachments: string[];
  wins: number;
  losses: number;
  draws: number;
}

const gamesOf = (row: MetaPlayerRow) => row.wins + row.losses + row.draws;
const archetypeKey = (detachments: string[]) => detachments.join(' + ');
const byName = (a: string | null, b: string | null) =>
  a === null ? (b === null ? 0 : 1) : b === null ? -1 : a.localeCompare(b);

interface Tally {
  players: number;
  games: number;
  points: number; // wins + ½ draws
  x1: number;
}
const emptyTally = (): Tally => ({ players: 0, games: 0, points: 0, x1: 0 });
function add(tally: Tally, row: MetaPlayerRow): void {
  tally.players += 1;
  tally.games += gamesOf(row);
  tally.points += row.wins + row.draws / 2;
  if (row.losses <= 1) tally.x1 += 1;
}
const figures = (tally: Tally, total: number) => ({
  players: tally.players,
  share: total === 0 ? 0 : tally.players / total,
  games: tally.games,
  winRate: tally.games === 0 ? 0 : tally.points / tally.games,
  x1: tally.x1,
  x1Share: tally.players === 0 ? 0 : tally.x1 / tally.players,
});

/** Popularity and results per faction, with archetypes (faction + detachments) inside. */
export function computeMeta(rows: MetaPlayerRow[]): {
  factions: MetaRow[];
  totals: { players: number; games: number };
} {
  const counted = rows.filter((row) => gamesOf(row) > 0);
  const byFaction = new Map<
    string | null,
    { tally: Tally; archetypes: Map<string, { detachments: string[] | null; tally: Tally }> }
  >();
  for (const row of counted) {
    const group = byFaction.get(row.faction) ?? { tally: emptyTally(), archetypes: new Map() };
    add(group.tally, row);
    const key = row.detachments.length === 0 ? '' : archetypeKey(row.detachments);
    const archetype = group.archetypes.get(key) ?? {
      detachments: row.detachments.length === 0 ? null : row.detachments,
      tally: emptyTally(),
    };
    add(archetype.tally, row);
    group.archetypes.set(key, archetype);
    byFaction.set(row.faction, group);
  }
  const total = counted.length;
  const factions: MetaRow[] = [...byFaction.entries()]
    .map(([faction, group]) => ({
      faction,
      ...figures(group.tally, total),
      archetypes: [...group.archetypes.values()]
        .map((a): ArchetypeRow => ({ detachments: a.detachments, ...figures(a.tally, total) }))
        .sort(
          (x, y) =>
            Number(x.detachments === null) - Number(y.detachments === null) ||
            y.players - x.players ||
            archetypeKey(x.detachments ?? []).localeCompare(archetypeKey(y.detachments ?? [])),
        ),
    }))
    .sort(
      (x, y) =>
        Number(x.faction === null) - Number(y.faction === null) ||
        y.players - x.players ||
        byName(x.faction, y.faction),
    );
  return {
    factions,
    totals: { players: total, games: counted.reduce((n, r) => n + gamesOf(r), 0) },
  };
}
```

`computeTeamMeta`: keep counted rows of team events; group by event → teams; an event counts only when every team row has a non-null `teamPlacing`; top = `placing <= Math.ceil(teamCount * 0.25)` (teamCount = distinct teams of the event); tally slots per faction and per archetype for top and all; shares = slots ÷ total top slots / total slots (0 when the total is 0); `difference = topShare - allShare`; sort factions (and archetypes) by difference desc, then all slots desc, then name; return `null` when no event counts.
